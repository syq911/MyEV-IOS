**凭据约定（重要）**：两个 PAT 作用域不同，分开存放，不要混用：

### 关键设计决策
1. **GRDB 作为本地包的远程依赖引入**（`Packages/AppDatabase/Package.swift` 声明

   `XCRemoteSwiftPackageReference` 的失败面。CI 实测：`Resolve Swift packages`
   一次通过，GRDB 7.11.1 正常解析编译。
2. **书架存「查询列 + JSON payload」**：payload 是唯一事实来源，投影列只服务
   排序/筛选/置顶并建索引；模型加字段无需迁移；读路径只用
   `String/Int.fetchOne|fetchAll`，对外部库 API 依赖面窄。
3. **夹具用外部实现生成**：deflate 测试夹具由 Python `zipfile` 生成并 base64 内联，
   避免"用自己的编码器验证自己的解码器"的自证循环；另加用例防止生成器写坏。
4. IPA 从 242KB 涨到 1.36MB —— GRDB 已真实链接进包（可用作"集成成功"的旁证）。
